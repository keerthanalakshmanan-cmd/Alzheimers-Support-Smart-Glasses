# AI-Powered Smart Glasses for Alzheimer's Support

## Project Overview
This project explores the design of AI-powered smart glasses intended to support people living with Alzheimer's through intelligent assistance and voice-based interaction.

## Problem Statement
People with Alzheimer's may experience memory difficulties, confusion, and challenges in remembering daily activities. This project aims to explore how wearable technology and AI can provide supportive assistance.

## Proposed Features
- Voice-based interaction and assistance
- Reminders for daily activities
- Personalized prompts and guidance
- Recognition of familiar people or objects (proposed feature)
- Supportive responses based on stored preferences and observations
- Privacy-conscious handling of personal information

## Technologies to Explore
- Python
- Artificial Intelligence
- Machine Learning
- Speech Recognition
- Computer Vision
- IoT and wearable technology

## Current Status
Concept development and research.

## Future Scope
Developing a working prototype, integrating AI models, and evaluating usability and privacy.
